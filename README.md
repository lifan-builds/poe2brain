# poe2brain

Agent-native Path of Exile 2 (`0.5.5` / `Forbidden Rites`) intelligence engine exposing both a typed CLI (`poe2`) and an MCP server (`poe2brain-mcp`) over four pillars:

1. **Knowledge & Mechanics** (`poe2brain.knowledge`)
2. **Headless Path of Building 2 Engine** (`poe2brain.pob`)
3. **Live Trade & Currency Economy** (`poe2brain.trade`)
4. **Exact Crafting Odds & Cost Planner** (`poe2brain.crafting`)
