# PoE2Brain (`0.5.5` / `Forbidden Rites`)

Use `poe2brain` (`poe2` CLI `--json` and `poe2brain` MCP server) as the single source of truth for Path of Exile 2. Never rely on pretrained LLM memory for PoE2 mechanics, base types, support gem limits, currency ratios, or crafting levers.

## Surface Routing: `poe2` CLI vs `poe2brain` MCP

Both surfaces call the same typed Python engine in the local `poe2brain` checkout.
- **In shell-capable coding harnesses (Antigravity, Claude Code, Codex, Devin):** Prefer `uv --directory <poe2brain-checkout> run poe2 ... --json` when batching calls, piping item text from files, or filtering large outputs with `jq`.
- **For single-turn lookups or chat-only harnesses:** Call the matching `poe2brain` MCP tool directly.

## Mandatory Anti-Hallucination Guardrails (Zero Tolerance)

1. **Never apply PoE1 or stale Patch `0.1` rules.** Before stating any mechanic or formula, call `poe2_explain_mechanic` or read [mechanics-0.5.5.md](references/mechanics-0.5.5.md):
   - **Conversion scales post-conversion types ONLY** (2-step `Skill -> Gear/Tree`, zero PoE1 double-dipping; DoTs cannot convert).
   - **Weapon/Armour Quality is `1% MORE` (multiplicative)**, not additive with local `% increased`. Attributes grant **0 per level** (`Str = +2 Life`, `Dex = +6 Accuracy`, `Int = +2 Mana`).
   - **Support Gems (`0.3+`)**: Standard supports are Tiered (`I`/`II`/`III`) and **can be equipped on multiple skills** (max 1 per `SupportGemCategory` per skill). Only **Lineage Supports** (and persistent global Spirit supports) are capped at `1 per character`.
   - **Defenses (`0.5.5`)**: Base passive Block cap is **`50%`** (NOT 75%). **Deflection** mitigates `40%` of hit/ailment damage independently of Evasion (`95%` cap). **Chaos deals `2x` damage to ES** (does NOT bypass ES), whereas **Bleeding AND Poison both bypass ES** directly to Life. **Grim Feast** is a Minion Revival skill (no longer doubles ES).
2. **Exalted Orb (`1.0`) is the unit currency**, not Chaos (`1 Divine ≈ 450–465 Exalted`, `1 Chaos ≈ 36 Exalted` in `Forbidden Rites`). Never treat missing/unpriced crafting currencies as `0` cost.
3. **Never hallucinate removed bases or crafting levers**:
   - PoE1 bases (`Vaal Regalia`, `Hubris Circlet`, `Astral Plate`, `Stygian Vise`) and removed `0.1` `Expert ` prefixes (`Expert Hexer's Robe` -> `Hexer's Robe`) fail in `0.5.5` — validate every base with `poe2_inspect_base`.
   - In-game PoE2 tooltips since `0.2.1` use **`Tier 1` (`display_tier = 1`) = BEST tier** (internal `.datc64` `internal_rank_asc = 1` is worst).
   - Zero Scouring, Alteration, Fusing, Chromatic, Fossils, or Crafting Bench. **`Omen of Homogenising Exaltation` / `Coronation` (removed in `0.4`)** and **Recombinators (`Omen of Recombination`, phased out in `0.5`)** do NOT drop in `0.5.5`.
4. **Never scrape dead/protected endpoints, emit unvalidated `.filter` syntax, or violate GGG ToS**:
   - `poe.ninja`'s PoE2 `/stash/` endpoint returns `HTTP 404`, `/api/protected/poe2/builds/...` is Cloudflare-gated (`HTTP 403`), and `poe2scout.com/api` returns HTML — always use `poe2brain`'s verified clients (`api.poe2scout.com`, `poe.ninja/poe2/api/economy/exchange/current/overview`, `poe.ninja/poe2/pob/raw/overview/code`, and `pathofexile.com/api/trade2`).
   - Never hand-emit raw PoE2 `.filter` rules without `poe2_filter_validate` (raw SQLite `item_class` IDs like `Body Armour`/`Warstaff`, stale `BaseType`s like `"Fist of Kalguur"`, or `HasExplicitMod >= 2` spaces crash PoE2 filter load!).
   - Strictly read-only public APIs and clipboard text: never read `POESESSID`, inject game inputs, automate trade clicks, or send automated whispers.

## Core Decision Playbooks

### Playbook A: Meta/Ascendancy Selection, Build Audit, Progression Diff & HC Survival
Read [pob2-workflows.md](references/pob2-workflows.md) (and [mechanics-0.5.5.md](references/mechanics-0.5.5.md) when mechanics interact).
1. **Verify Live Meta & Ascendancy Notables**: For *"best build / best ascendancy / SSF reroll"* prompts, call `poe2_meta_ladder` and `poe2_inspect_ascendancy` (all 23 PoE2 `0.5.5` Ascendancies; blocks PoE1/unreleased traps). For SSF chase drops (`Svalinn`, `Choir of the Storm`, `Rakiata's Flow`), run `poe2_ninja_search --ssf-viable --exclude-unique "Temporalis,Mageblood,Headhunter,Kalandra's Touch"` to isolate low-unique setups without T0 co-dependencies.
2. **Load, Dewater & Diff Progression Slots**: Load `eN...` codes or `poe.ninja` characters into `main` (and early snapshots into `early` via `poe2_ninja_character --probe-timeline` -> `--timemachine <earliest> --load-pob --slot early`). Run `poe2_pob_audit` to strip PoB-warrior inflation, and run `poe2_pob_compare --slot-a early --slot-b main --dewater` for exact gear/skill/keystone diffs and `0.5.5` Gold respec cost (`1x` passive, `5x` Ascendancy; Orbs of Regret do not exist).
3. **Run Hardcore / Pinnacle Rip Audits (`poe2_pob_hc_audit`)**: On HC or Pinnacle boss builds, call `poe2_pob_hc_audit` to verify sustainable Phys/Ele/Chaos Max Hits, catch lethal **non-CI Low-Life ES Bleed/Poison bypass** (`bleed_poison_es_bypass`) and **Chaos `2x` ES damage** (`chaos_2x_es_vulnerability`), check Belt Charms, and rank top defensive EHP passive respecs with exact Gold cost.
4. **Optimize Tree, Radius Jewels, Gems, What-If Hypotheses & Gear Upgrades**: Run `poe2_pob_calc_breakdown` to explain where any stat (`FullDPS`, `ManaCost`, `EnergyShield`, `CritChance`) comes from (`BASE`/`INC`/`MORE`), `poe2_pob_suggest_nodes` (`perPoint`/`total`/`anoint`), `poe2_pob_radius_jewels` (`Controlled Metamorphosis` / `Against the Darkness` socket × ring placement), `poe2_pob_supports` (full `GetMiscCalculator()` Tier `I`–`III` + Lineage support ranking with Mana/Spirit/conflict checks), `poe2_pob_what_if` (transactional multi-change experiments & borrowed reference-slot attribution), and `poe2_pob_stat_weights` -> `poe2_find_upgrades` (with automatic `20%` Quality + Greater Rune top-off normalization on non-corrupted candidates).

### Playbook B: Clipboard Item Price-Checking, Quad-Tab Triage & Budget Upgrade Hunting
Read [trade-economy.md](references/trade-economy.md).
1. **Single Item vs Multi-Item Dump Triage**: Run `poe2_price_check` for a single item, or **`poe2_triage_dump` (`poe2 trade triage`)** on multi-item `Ctrl+C` pastes/files to split and classify mixed quad-tab dumps into `sell_instant` (Alva stackables / Instant Buyout), `craft_finish_ev` (open-affix fractured/T1 rares), `high_variance_id_or_unveil` (`Unidentified (Tier 3–5)` or unrevealed `Desecrated`), and `salvage_or_vendor`.
2. **Report Clean Buyout Market Prices & Fixer Warnings**: Anchor quotes to `securable_min_exalted` / `securable_median_exalted` silently (every PoE2 player already buys via instant buyout by default; don't over-explain or pitch buyout vs whisper as a feature) and surface `fixer_warnings` only when low-end outliers distort the range.
3. **Hunt Budget Upgrades**: When shopping for a slot upgrade, pass `--max-exalted <budget>` to `poe2_find_upgrades` so every candidate is evaluated inside headless PoB2 (`GetMiscCalculator()`) with automatic `+20%` quality + Greater Rune top-off rather than judged by eye.

1. **Scan Profitable Crafts First**: When asked *"what craft is most profitable?"*, run `poe2_scan_craft_profit` (`--budget all|low|mid|high`) to rank deterministic & positive-EV crafts with sanitized live input costs, `p50`/`p80` drawdowns, live `trade2` `securable` `p10`/`median` exit prices, listing depth, and step-by-step recipes while flagging negative-EV traps.
2. **Mid-Craft Bench Rescue (`poe2_craft_odds --protect-existing`)**: On partially finished high-value Rares (`--item-text`), `poe2_craft_odds` defaults to `protect_existing_targets=True` so `0%`-collateral moves (`Omen of Whittling` sniping lowest `required_level` non-fractured bricks, `Sinistral/Dextral Crystallisation`, `Omen of Light`) rank ahead of raw Chaos/swap moves that risk bricking finished T1 affixes.
3. **Simulate Optimal `0.5.5` Policy & Tail Risk**: Anchor `buy_price_ex` via `poe2_price_check`, verify base/breakpoints via `poe2_inspect_base`, and run `poe2_craft_plan --base "<base>" --ilvl <ilvl> --target ... --buy-exalted <buy_price_ex> --sims 3000`. Recommend **Buy** when `buy_price_ex <= expected_cost_exalted` or bankroll cannot absorb `p80_cost_exalted`.

Read [filters-and-ninja.md](references/filters-and-ninja.md) and [pob2-workflows.md](references/pob2-workflows.md).

2. **Compile Solo/Co-op, CVD-Safe & 2 AM Tinnitus-Safe Filters (`poe2_filter_generate` / `poe2_filter_restyle`)**:
   - Pass `--slot main` or `--slots p1,p2` (co-op party union preserving both players' weapons, offhands, armour tags, and uncapped resists), `--cvd-safe deuteranopia|protanopia` (`10` unique minimap shapes + zero red/green conflicts), `--warm-night` / `--lowpass-hz` (`<1.5%` HF energy `>2.5 kHz` 4th-order Butterworth LPF), and `--callout tier="phrase"` for spoken callouts.
   - Use `poe2_filter_restyle <path_or_strictness>` to restyle local or MIT NeverSink `0.10.4a` filters while auto-healing stale `BaseType`s.
3. **Doctor Broken Legacy Filters (`poe2_filter_heal`) & Validate (`poe2_filter_validate`)**: When a user pastes a broken PoE1 or Patch `0.1` `.filter` (`MapTier`, `SocketGroup`, `Expert ` prefixes, singular `Class == "Body Armour"`, `HasExplicitMod >= 2`, `Continue` ordering), run **`poe2_filter_heal`** (`poe2 filter heal <file> --out <healed.filter>`) to repair it to `0` validation errors; pass `--install` only when explicitly requested.
